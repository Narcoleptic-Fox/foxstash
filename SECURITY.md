# Security Policy

## Supported Versions

Security fixes are applied to the **latest published minor release** of each crate.
Older minor versions do not receive backported security patches.

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |
| older   | No        |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

### Option 1 — GitHub Private Security Advisory (preferred)

Use GitHub's built-in private reporting:
[Report a vulnerability](https://github.com/Narcoleptic-Fox/foxstash/security/advisories/new)

This creates a private draft advisory that only maintainers can see.

### Option 2 — Email

Send a report to **dev@narcolepticfox.com** with the subject line:
`[foxstash] Security Vulnerability Report`

Include as much detail as possible:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- The crate(s) and version(s) affected
- Any suggested mitigations

## Response Timeline

| Stage | Target |
| ----- | ------ |
| Acknowledgement | Within 48 hours |
| Initial assessment | Within 5 business days |
| Fix or mitigation | Depends on severity and complexity |
| Public disclosure | Coordinated with the reporter |

We follow responsible disclosure and will coordinate the public announcement
with you before publishing a fix or advisory.

Thank you for helping keep foxstash and its users safe.
